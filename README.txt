Power House Auction Hub - final copy (23 Oct 2026)
By C Laxmi Deepak. Co-founder: Varshith.

Folders: hub, profile, ipl, kabaddi, bbl, wpl. Each page is one self-contained .html file; open it in any browser.

Notes
- Links between pages (nav bar, Hub cards) point to the live claude.ai pages, so they need internet and the page set to "Anyone with the link".
- The live auction rooms (play.html) and the WPL home use the Claude artifact runtime for rooms, chat and reviews. Those features only work when the page is hosted as a Claude artifact; the page still opens offline but rooms will not connect.
- The included index.html opens the self-contained hub page that does not depend on the omitted 3D asset bundle.
- To host elsewhere for free, upload this folder to GitHub Pages, Cloudflare Pages, or another static host.
- The navigation intentionally keeps the Claude artifact links for live rooms, chat and reviews. Those features remain dependent on Claude's artifact runtime and permissions.
- If the site is moved fully away from Claude, replace those links and rebuild the live-room backend before advertising multiplayer functionality.
- Fan-made and unofficial; not affiliated with the IPL, WPL, Pro Kabaddi or the BBL.
