Folders: hub, profile, ipl, kabaddi, bbl, wpl. Each page is one self-contained .html file; open it in any browser.

Notes
- Links between pages (nav bar, Hub cards) point to the live claude.ai pages, so they need internet and the page set to "Anyone with the link".
- The live auction rooms (play.html) and the WPL home use the Claude artifact runtime for rooms, chat and reviews. Those features only work when the page is hosted as a Claude artifact; the page still opens offline but rooms will not connect.
- To host elsewhere, upload the folders to any static host and replace the claude.ai links with your own domain.
- Fan-made and unofficial; not affiliated with the IPL, WPL, Pro Kabaddi or the BBL.
